# Artifacts

This repository publishes static folders as public GitHub Pages sites. It is managed by [`llm-artifacts`](https://github.com/pedrocarvajal/llm-artifacts).

- Every artifact lives in its own folder: `<slug>/`.
- Its metadata lives in `_meta/<slug>.json`.
- The index at `/` is generated by `tools/build-index.ts` during deployment.
- `_meta/` and `tools/` are never published.

URL: `https://<owner>.github.io/<repository>/<slug>/`. The CLI prints the exact URL.

Do not edit an artifact by hand. Use the CLI:

```bash
llm-artifacts publish /tmp/my-page
llm-artifacts list
llm-artifacts remove my-page
```

Anything in this repository is public, including its git history. Never commit a secret.
