02

Cómo se publicó

El CLI validó la carpeta, la copió a staging, la escaneó, creó un commit y esperó el deployment antes de devolver la URL. 

llm-artifacts publish \
  ./llm-artifacts-example \
  --slug example

Un artifact es un commit. La historia de git es el historial de versiones.

03

Qué puedes probar

El botón de tema, el de copiar y el contador. Todo ocurre en el navegador, sin red y sin almacenamiento compartido.

El recorrido

Lo que ocurre entre la carpeta y la URL.

  1. 01validar

    Tamaño, secretos, index.html.

  2. 02stage

    Copia aislada en la caché local.

  3. 03commit

    Un artifact, un cambio atómico.

  4. 04deploy

    Actions construye el sitio y el índice.

  5. 05verify

    La URL responde antes de terminar.
